# Responsible Use

EduLens Academic Performance Analytics predicts academic performance based on statistical relationships found in the training data.

## Guidelines
- **Educational Context:** The system is an analytical demonstration. It is not an oracle.
- **No Causal Claims:** Variables such as "Lunch Program" correlate with performance but do not explicitly cause it.
- **Bias Awareness:** Models trained on historical data may propagate existing systemic biases.
- **Prohibited Uses:** Do not use this tool for admissions filtering, scholarship allocation, or disciplinary action.
