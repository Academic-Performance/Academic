# UI/UX Design

EduLens Academic Performance Analytics uses a custom design system focused on:
- **Professional Aesthetics:** Removing generic bootstrap styles in favor of a modern, clean interface.
- **Accessibility:** Ensuring contrast ratios, focus states, and semantic HTML are maintained.
- **Micro-interactions:** Subtle hover states, smooth transitions, and dynamic score revelations.
- **Responsiveness:** Full support for mobile, tablet, and desktop viewports.

## Color Palette
- Primary: Blue (`#3b82f6`)
- Surface: White (`#ffffff`)
- Background: Slate (`#f8fafc`)
